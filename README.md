# Windows Server & Active Directory Administration

Course project for "Engineering of Windows Server OS," covering core Windows Server administration topics in a hands-on lab environment.

## Topics covered (see `report/`)

- Introduction to Windows Server and Active Directory
- User account configuration (GUI and PowerShell)
- Group configuration and management
- File/folder permissions and network share configuration
- Group Policy Objects (GPOs) for remote configuration of computers and user accounts
- Remote software installation and configuration via Group Policy
- DNS service configuration

## Contents

- `report/ActiveDirectory_Project_Report.docx` — full project report documenting the Active Directory lab work.
- `scripts/` — Python helper scripts used to assemble and generate the project report.
